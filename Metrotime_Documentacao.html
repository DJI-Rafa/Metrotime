📱 METROTIME — Documentação Completa da Aplicação

1. Visão Geral

Metrotime é uma aplicação nativa Android desenvolvida em Kotlin com Jetpack Compose, destinada a fornecer informações de transportes públicos em tempo real na área metropolitana de Lisboa. A app cobre Metro de Lisboa, Comboios CP, Autocarros Carris/Carris Metropolitana e Barcos (Transtejo/Soflusa).

Aspeto Detalhe
Linguagem Kotlin
UI Framework Jetpack Compose (Material 3)
Arquitetura MVVM + Repository Pattern
Backend Firebase Auth, Firebase Realtime Database
APIs Externas Metro de Lisboa API, Comboios.live API
Dados Offline GTFS estáticos (CP, Carris, Transtejo)
Mapa MapLibre GL (open-source)
Min SDK Android 8.0 (API 26)

2. Sistema de Autenticação

2.1 Ecrã de Login (LoginScreen.kt)

  • Login por email/password via Firebase Authentication.
  • Login com Google Sign-In (OAuth 2.0) com botão estilizado.
  • Navegação para registo e recuperação de palavra-passe.
  • Design premium com gradiente escuro e logo da Metrotime.

2.2 Ecrã de Registo (RegisterScreen.kt)

  • Criação de conta com nome, email e palavra-passe.
  • O nome do utilizador é guardado na Firebase Realtime Database em /users/{uid}/name.

2.3 Recuperação de Password (ForgotPasswordScreen.kt, ResetPasswordScreen.kt)

  • Envio de email de reset via Firebase.

2.4 Splash Screen (SplashScreen.kt)

  • Ecrã de carregamento de 750ms com animação antes de redirecionar para o ecrã principal.

3. Ecrã Principal (SettingsActivity.kt)

O ecrã principal é o hub central da app e divide-se em duas áreas:

3.1 Barra Superior

  • Avatar do utilizador (foto de perfil carregável do dispositivo, guardada em Base64 na Firebase).
  • Menu dropdown: Mudar foto / Logout.
  • Botão Amigos (ícone de pessoa) → abre FriendsActivity.
  • Botão Definições (ícone de engrenagem) → abre o painel de definições e administração.

3.2 Toggle Metro / Comboio

Barra de alternância animada entre os dois modos de transporte.

3.3 Tab Metro (MetroTabContent)

  • 4 botões de linha: Azul, Amarela, Verde e Vermelha (cada um com a cor oficial).
  • Ao clicar, abre a lista de estações dessa linha (LineStationsActivity).
  • 2 botões de ação no fundo:
  • Live Map → abre o mapa em tempo real (LiveMapActivity).
  • Favoritos → abre as estações favoritas (FavoritesActivity).

3.4 Tab Comboio (ComboioTabContent)

  • Barra de pesquisa de estações CP.
  • Toggle Estações / Comboios em Circulação.
  • Lista de estações CP filtráveis (dados da API Comboios.live).
  • Lista de comboios ativos com badge colorido por tipo de serviço (AP, IC, IR, R, U, S).
  • Ao clicar numa estação → CpStationActivity.
  • Ao clicar num comboio → CpTripDetailActivity.

4. Metro de Lisboa — Funcionalidades

4.1 Lista de Estações por Linha (LineStationsActivity.kt)

  • Apresenta todas as estações da linha selecionada, ordenadas.
  • Cada estação é clicável e abre a vista de chegadas.

4.2 Chegadas em Tempo Real (StationArrivalsActivity.kt)

  • Tempos de espera do Metro agrupados por destino, com contagem regressiva ao segundo (mm:ss).
  • Barra colorida lateral por linha (Azul, Amarela, Verde, Vermelha).
  • Botão de Favorito ⭐ na TopAppBar para guardar a estação.
  • Autocarros próximos (< 1km) via dados GTFS Carris, com badge amarelo do número da carreira, destino e ETA.
  • Barcos (apenas em Cais do Sodré e Terreiro do Paço): horários Transtejo/Soflusa com cores por operador.
  • Toggle "Autocarros / Barcos" nas estações com ambos os modos.

4.3 Dados do Metro

  • API em tempo real: https://api.metrolisboa.pt/ para tempos de espera ao segundo.
  • Estações: Ficheiro JSON local com todas as estações, coordenadas GPS, linhas e API IDs.

5. Comboios CP — Funcionalidades

5.1 Estação CP (CpStationActivity.kt)

  • Lista de comboios que param na estação selecionada.
  • Filtro por tipo de serviço (Todos / AP / IC / IR / R / U).
  • Cada cartão mostra: número do comboio, origem → destino, tipo de serviço, atraso, estado.
  • Botão de Favorito ⭐ na TopAppBar.
  • Filtragem inteligente via Route Cache (GTFS) — a app sabe exatamente quais comboios param em cada estação.

5.2 Detalhe de Viagem (CpTripDetailActivity.kt)

  • Timeline visual de todas as paragens do comboio.
  • Paragens já passadas marcadas a vermelho.
  • Paragem atual destacada.
  • Paragens futuras a branco.
  • Horários previstos de chegada/partida com atraso incorporado.
  • Indicador de progresso do comboio na timeline.
  • Informações: número, serviço, velocidade, operador, atraso acumulado.

5.3 Motor de Rotas e Cache (CpRouteRepository.kt)

  • Cache inteligente em memória de todas as rotas dos comboios.
  • Utiliza dados GTFS estáticos (ficheiro stop_times.txt com ~300k linhas) para resolver rotas completas.
  • Lazy Loading: Carrega apenas as rotas dos comboios ativos.
  • Background Warmup: O serviço em background aquece o cache a cada 5 minutos, mesmo sem a app aberta.
  • Fallback automático: Se a API falhar, usa dados GTFS offline.

5.4 GTFS Estáticos (CpGtfsRepository.kt)

  • Ficheiros GTFS oficiais da CP embebidos na app (assets/).
  • Mapeamento de trip_id → lista ordenada de paragens com horários.
  • Utilizado para reconstruir rotas quando a API Comboios.live restringe detalhes.

6. Mapa ao Vivo (LiveMapActivity.kt + LiveMapViewModel.kt)

6.1 Mapa Interativo

  • Motor de renderização: MapLibre GL (open-source, baseado em Mapbox).
  • Estilo escuro personalizado.
  • Linhas do Metro desenhadas como LineLayer com as cores oficiais.
  • Estações representadas como pontos brancos com contorno cinza.
  • Comboios em movimento: Setas brancas direcionais com rotação baseada no bearing.
  • Comboios fantasma (sem sinal GPS): Setas semi-transparentes com posição estimada.

6.2 Motor de Posicionamento (TrainPositionEngine.kt)

  • Calcula a posição em tempo real de cada composição do Metro entre duas estações.
  • Interpolação linear baseada no tempo restante até à próxima estação.
  • Cálculo de bearing (ângulo de direção) para orientar as setas no mapa.
  • Escala dinâmica das setas conforme o nível de zoom.

6.3 Info Sheets

  • Toque num comboio: Abre bottom sheet com linha, destino, próxima estação, tempo restante, ID.
  • Toque numa estação: Abre bottom sheet com próximas chegadas em tempo real.

6.4 Localização de Amigos no Mapa

  • Amigos com partilha ativa aparecem como círculos azuis com a inicial do nome ou foto de perfil recortada em círculo.
  • Atualização contínua via Firebase Realtime Database.

6.5 Localização do Utilizador

  • Indicador azul pulsante com a posição GPS do utilizador.
  • Permissão de localização em primeiro plano.

7. Sistema de Amigos (FriendsActivity.kt)

7.1 Funcionalidades

  • Adicionar amigos por código UID.
  • Lista de amigos com nome, foto de perfil e estado.
  • Pedidos de amizade pendentes (enviar/aceitar/rejeitar).
  • Dados sincronizados via Firebase Realtime Database em /friendships/.

8. Sistema de Favoritos (FavoritesActivity.kt)

8.1 Interface

  • Duas tabs: "Metro" e "Comboio" com toggle animado.
  • Estado vazio: Logo do Metro de Lisboa ou CP com mensagem instrutiva.

8.2 Metro Favorites

  • Lista de estações de metro favoritas com barra colorida por linha.
  • Toque para abrir a estação.
  • Swipe to Remove: Arrastar para a esquerda revela fundo vermelho "Remover".

8.3 CP Favorites

  • Lista de estações CP favoritas com logo da CP.
  • Mesmo comportamento de swipe-to-remove e toque para abrir.

8.4 Persistência

  • Guardado localmente via SharedPreferences (sobrevive a reinstalações se backup estiver ativo).

9. Widgets para Ecrã Inicial e Ecrã de Bloqueio

9.1 Widget Principal (MetroWidgetProvider, widget_metro.xml)

  • Widget para o ecrã inicial com design escuro semi-transparente (glassmorphism).
  • Mostra a estação mais próxima e os 3 próximos comboios por destino com tempos ao segundo.
  • Toque para atualizar manualmente.
  • Atualização automática a cada segundo via WidgetUpdateService.

9.2 Widget de Ecrã de Bloqueio (LockWidgetProvider, widget_lock.xml)

  • Widget compacto para o lock screen (compatível com ONE UI).
  • Mostra estação + 3 próximas chegadas.
  • Estilo frosted glass.

9.3 Notificação Persistente no Lock Screen

  • Notificação custom com layout colapsado e expandido.
  • Layout colapsado: Estação + próximo comboio + tempo.
  • Layout expandido: Estação + 3 próximos comboios.
  • Visibilidade pública (visível sem desbloquear).
  • Ícone de notificação: silhueta de comboio em branco (ic_stat_metro).

10. Serviço em Background (WidgetUpdateService.kt)

10.1 Foreground Service

  • Serviço persistente que mantém a app viva em background.
  • Tipo: dataSync + location.
  • Retorno START_STICKY (o Android reinicia-o se o sistema o matar).

10.2 Loop Principal (tick a cada 1 segundo)

Intervalo Ação
1 segundo Atualiza widgets, lock widget e notificação
15 segundos Re-fetch dados do Metro via API
60 segundos Partilha localização GPS na Firebase
60 segundos Verifica se o utilizador está num comboio CP
60 segundos Verifica estado dos amigos em comboios
60 segundos Verifica mensagens admin na Firebase
5 minutos Aquece o cache GTFS de rotas CP

10.3 Deteção Automática de Comboio CP

  • Compara a localização GPS do utilizador com as posições dos comboios da API Comboios.live.
  • Se o utilizador estiver a < 200m de um comboio, inicia tracking.
  • Após 3 verificações consecutivas a mover-se com o mesmo comboio → confirmação.
  • Publica currentTrain e trainDestination na Firebase.
  • Os amigos são notificados automaticamente com mensagem personalizada (ex: "O João está a viajar no IC 523 para o Porto!").

10.4 Notificações de Amigos em Comboios

  • Lê o campo currentTrain dos amigos na Firebase.
  • Envia notificação local com o logo da CP como ícone grande.
  • Mensagens personalizáveis com templates variados para evitar repetição.
  • Deduplicação: cada viagem só notifica uma vez.

10.5 Boot Receiver (BootReceiver.kt)

  • Escuta BOOT_COMPLETED e MY_PACKAGE_REPLACED.
  • Reinicia automaticamente o WidgetUpdateService após reboot ou atualização da app.
  • Os widgets nunca param, mesmo após desligar e ligar o telemóvel.

11. Painel de Administração

11.1 Acesso

  • Protegido por palavra-passe hardcoded.
  • Acessível via Definições → "Área Reservada (Equipa)".

11.2 Funcionalidades

  • Cache de Rotas: Visualização de todas as rotas memorizadas com origem → destino.
  • Privacidade: Toggle de partilha de localização em background.

11.3 Push Notifications Remotas

  • Seleção de destinatários: Chips clicáveis com todos os utilizadores registados.
  • Botão "Todos": Envia para toda a base de utilizadores.
  • Campo de mensagem: Texto livre para a notificação.
  • Mecanismo: Escreve na Firebase em /adminMessages/{uid}. O serviço em background de cada utilizador deteta a mensagem, mostra a notificação e apaga-a da BD.
  • Canal de alta prioridade: Garante entrega imediata (admin_alerts).

12. Autocarros Carris (GtfsRadarService.kt)

12.1 Funcionamento

  • Utiliza dados GTFS estáticos da Carris/Carris Metropolitana.
  • Radar de proximidade: Identifica paragens de autocarro num raio de 1km da estação de metro selecionada.
  • Calcula ETA baseado nos horários programados do GTFS.
  • Apresenta: número da carreira, destino, paragem e tempo estimado.

13. Barcos Transtejo/Soflusa (BoatScheduleRepo.kt)

13.1 Funcionamento

  • Dados GTFS estáticos das empresas Transtejo e Soflusa.
  • Disponível em Cais do Sodré e Terreiro do Paço.
  • Mostra próximas partidas com: destino, horário, ETA em minutos, operador.
  • Cores por operador: Transtejo (laranja), Soflusa (vermelho).

18. Design e UX

  • Tema escuro consistente em toda a aplicação (DarkBackground, CardBackground).
  • Cores oficiais: Azul (#2E86DE), Amarela (#F7DC6F), Verde (#27AE60), Vermelha (#E74C3C).
  • Tipografia: Material 3 com pesos variados (Bold, SemiBold, Medium).
  • Animações: Transições suaves nos toggles, cores animadas, efeitos de seleção.
  • Glassmorphism: Widgets com fundo semi-transparente e blur.
  • Micro-interações: Swipe-to-remove nos favoritos, chips de seleção, contagem regressiva ao segundo.
  • Responsividade: Layouts adaptáveis com LazyColumn, FlowRow e weight().
